# EverPia — La teva porta d’entrada al món de la consultoria IT

Benvinguts a **EverPia**, una **consultora IT** amb una missió clara: **resoldre els reptes tecnològics** de clients molt diversos, ajudant-los a créixer mitjançant solucions innovadores i sostenibles.  

A partir d’avui, **t’incorpores com a consultor/a júnior** a l’equip d’EverPia. Treballaràs amb organitzacions diferents, amb necessitats úniques i desafiaments reals.  
Cada projecte pot semblar independent, però tots formen part d’una mateixa aventura: **aprendre, adaptar-se i col·laborar** per oferir **solucions d’alta qualitat**.

## Objectiu del Projecte

Com a **consultor/a júnior**, el teu repte és:
- Desenvolupar **competències tècniques i professionals**  
- Treballar amb **metodologies àgils**  
- Comunicar i documentar amb claredat  
- Lliurar **projectes de qualitat**, amb **organització i rigor**

Treballarem amb:
- **Metodologia Kanban**  
- **Eina Planner**  
- **Repositori GitHub** amb documentació en **Markdown**

---

##  Competències Clau

-  Adaptació a diferents entorns i reptes  
-  Organització i planificació  
-  Comunicació clara i documentació tècnica  
-  Treball col·laboratiu i esperit de consultoria  
-  Compromís amb la qualitat i la sostenibilitat  

---

## Tasques i Reptes

Al llarg del projecte, afrontaràs tasques com:
- Creació i configuració del teu **compte de GitHub**  
- Documentació amb **Markdown**  
- Selecció d’un **SAI** per protegir una empresa  
- Recuperació d’accessos a un sistema bloquejat  
- Configuració d’un **servidor Linux**  
- Desplegament de serveis de xarxa (**DHCP**, etc.)  
- Reflexions sobre **sostenibilitat tecnològica**  
- Desenvolupament d’una **pàgina web professional**
